# LEED GA Trainer - GitHub Pages / iOS Web Build

This folder is ready to upload to the root of a GitHub repository and publish with GitHub Pages.

## Publish
1. Create or open a GitHub repository.
2. Upload **all files and folders inside this package** to the repository root. `index.html` must remain at the root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch (usually `main`) and folder **/(root)**, then save.
6. Open the GitHub Pages URL after deployment finishes.

## Use on iPhone/iPad
1. Open the published URL in Safari.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Launch from the new Home Screen icon.

Progress and test history are stored locally in the browser on each device. They do not automatically sync across devices. After the first complete online load, the service worker caches the web app for later offline use.
